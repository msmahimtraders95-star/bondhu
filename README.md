# Bondhu

বন্ধুত্বের নতুন ঠিকানা।

Bondhu একটি Social Networking App। এখানে ব্যবহারকারীরা বন্ধুদের সাথে যুক্ত হতে, পোস্ট করতে, লাইক, মন্তব্য এবং শেয়ার করতে পারবে।

## App Name

Bondhu

## Main Features

- User Registration
- User Login
- User Profile
- Create Post
- Like
- Comment
- Share
- Friends
- Notifications
- Messenger
- Firebase Authentication
- Cloud Firestore
- AdMob
- Admin Panel

## Technology

- Flutter
- Dart
- Firebase
- Cloud Firestore
- Firebase Authentication
- Google Mobile Ads
